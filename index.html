Conecta tu clave de TMDB

Esta aplicación obtiene su catálogo de The Movie Database (TMDB). Necesitas una clave de API gratuita:

  1. Crea una cuenta en themoviedb.org.
  2. Entra a Ajustes → API y solicita una clave (uso personal/educativo).
  3. Copia la Clave de la API (v3) y pégala aquí.

La clave se guarda solo en este navegador (localStorage). También puedes escribirla en js/config.js.
